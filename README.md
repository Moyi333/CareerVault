# CareerVault (Android)

Registro de modo carrera estilo notas.

## Cómo obtener el APK (sin instalar nada)
1. Creá un repositorio en GitHub.
2. Subí TODO el contenido de esta carpeta, incluida la carpeta oculta `.github`.
   Si `.github` no se sube: en GitHub, Actions > "set up a workflow yourself" y pegá el contenido de `build.yml`.
3. Pestaña **Actions**: esperá a que termine "Build APK".
4. Bajá el artefacto **careervault-apk** (viene en un zip con `app-debug.apk`) e instalalo en el celu.

## Escudos
Al guardar un club, selección o clásico sin escudo, la app lo busca sola en Wikipedia (necesita internet).
Si no lo encuentra o es el equivocado, se puede elegir una imagen de la galería.
